# Udaan Events — React/Vite Website

Premium black/gold event-management website built with React, Vite, JavaScript, React Router DOM, Lucide React and CSS.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Restolier

Put the font file at:
`src/assets/fonts/Restolier.woff2`

The existing CSS automatically uses it as the display font. If the file is absent, Cormorant Garamond is used as the fallback.
